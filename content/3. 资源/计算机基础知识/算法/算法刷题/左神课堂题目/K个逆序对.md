## 题目描述

给定一个整数N，代表你有1～N这些数字。在给定一个整数K。你可以随意排列这些数字，但是每一种排列都有若干个逆序对。返回有多少种排列，正好有K个逆序对

例子1:

Input: n = 3, k = 0

Output: 1

解释：

只有[1,2,3]这一个排列有0个逆序对。

例子2:

Input: n = 3, k = 1

Output: 2

解释

[3,2,1]有(3,2)、(3,1)、(2,1)三个逆序对，所以不达标。

达标的只有：

[1,3,2]只有(3,2)这一个逆序对，所以达标。

[2,1,3]只有(2,1)这一个逆序对，所以达标。

## 题目解析

在这道题目中，我们首先得知道什么叫做逆序对，例子已经说明，看到了两个参数的要求，我们其实可以想到动态规划，两个参数，完全可以想到一个样本做行，一个样本做列的情况。

因此我们将n作为行，k作为列，行的范围时0-n，类的范围是0-k

第一行是没有意义的，可以忽略。（n=0）第二行中，只存在一个数，此时只有（k=0,n=1）的位置时1，其余位置都是0；再看第一列，当我们要求0个逆序对(k=0),此时都是1，因此我们能够得出基本位置。

此时去递推普通位置，依旧是从例子入手。

假设我们现在需要（7，3）的位置，那么我们就先假设我们已知(6,3)的值，最后的7如果插入在最后的位置，不增加逆序对，此时的值就是(6,3)；插入在倒数第二位置，此时产生一个逆序对，也就是(6,2)；以此类推，能到(6,0)；

再假设我们下载需要（7,8）的位置，那么也假设我们已知对应位置的值，插入在最后，为（6，8），以此类推，但是到最后我们到的位置是（6，2），因为如果再往前面，产生的逆序对将不满足。

抽象出来，可以得到如下公式：

$$
\begin{array}{l} 
dp[n][k] =
  \left\{\begin{matrix} 
    dp[n - 1][k..0] n >k\\
    dp[n-1][k..k-n+1] k>=n
\end{matrix}\right.    
\end{array}
$$
因此，可以写出第一版“粗糙”的动态规划。

```java
public static int dp1(int n, int k) {
        if (n < 1 || k < 0) {
            return 0;
        }
        int[][] dp = new int[n + 1][k + 1];
        for (int i = 1; i <= n; i++) {
            dp[i][0] = 1;
        }
        for (int i = 2; i <= n; i++) {
            for (int j = 1; j <= k; j++) {
                for (int s = j; s >= Math.max(j - i + 1, 0); s--) {
                    dp[i][j] += dp[i - 1][s];
                }
            }
        }
        return dp[n][k];
    }
```



其中有枚举行为，我们可以使用斜率优化，依旧使用例子。

对于（7，3），我们如果知道了 是`dp[6][3..0]`，但是对于(7，2)，以来的是`dp[6][2..0]`，因此这个位置就可以使依赖于(7,2)与(6,3)。

对于（7，8），上面知道了是依赖于`dp[6][8..2]`，此时的（7，7），依赖的是`dp[6][7..1]`，此时我们需要加上一个(6,8)同时减去一个(6,1)。

对于极端位置（k=1），此时也是满足。

抽象出来，得公式：

$$
\begin{array}{l} 
dp[n][k] =
  \left\{\begin{matrix} 
    dp[n][k - 1] + dp[n - 1][k] n >k\\
    dp[n - 1][k] + dp[n][k - 1] - dp[n - 1][k - n] k>=n
\end{matrix}\right.    
\end{array} 
$$


得出代码：

```java
public static int dp2 (int n, int k) {
        if (n < 1 || k < 0) {
            return 0;
        }
        int[][] dp = new int[n + 1][k + 1];
        for (int i = 1; i <= n; i++) {
            dp[i][0] = 1;
        }
        for (int i = 2; i <= n; i++) {
            for (int j = 1; j <= k; j++) {
                // dp[i][j] -> dp[i][j-1]
                // j == 1 dp[i][1] dp[i][0]
//                if (i > j) {
//                    dp[i][j] = dp[i][j - 1] + dp[i - 1][j];
//                }
//                if (j >= i) {
//                    dp[i][j] = dp[i][j - 1] + dp[i - 1][j] - dp[i - 1][j - i];
//                }
                dp[i][j] = dp[i][j - 1] + dp[i - 1][j] - (i <= j ? dp[i - 1][j - i] : 0);
            }
        }
        return dp[n][k];
    }
```

## 总结

**不管是什么模型 我们尤其关注开头与结尾**
