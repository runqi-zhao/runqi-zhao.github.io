# 股票问题

## 问题一

### 问题描述

给定一个数组arr，从左到右表示昨天从早到晚股票的价格。作为一个事后诸葛亮，你想知道如果只做一次交易，且每次交易只买卖一股，返回能挣到的最大钱数

标签：[[09_贪心算法]]，[[12_动态规划]]

### 问题解析

直接通过比较，选择出最大最小值，然后进行相加相减。

```Java
public class BestTimetoBuyandSellStock1 {
    public int maxProfit(int[] prices) {
      if (prices == null || prices.length == 0) {
          return 0;
      }
      int min = prices[0];
      int ans = 0;
        for (int i = 1; i < prices.length; i++) {
            min = Math.min(min, prices[i]);
            ans = Math.max(ans, prices[i] - min);
        }
        return ans;
    }
}
```

## 问题二

### 问题描述

给定一个数组arr，从左到右表示昨天从早到晚股票的价格

作为一个事后诸葛亮，你想知道如果随便交易，

且每次交易只买卖一股，返回能挣到的最大钱数

标签：

### 问题解析

这里的话因为是随便交易，那么在进行售卖的时候，只要大于0，直接售卖，如果小于0，则不进行售卖

```java
public class BestTimetoBuyandSellStock2 {
    public static int maxProfit(int[] prices) {
        if (prices == null || prices.length == 0) {
            return 0;
        }
        int min = prices[0];
        int ans = 0;
        for (int i = 1; i < prices.length; i++) {
            ans += Math.max(prices[i] - prices[i - 1], 0);
        }
        return ans;
    }
}
```

## 问题三

### 问题描述

给定一个数组arr，从左到右表示昨天从早到晚股票的价格

作为一个事后诸葛亮，你想知 道如果交易次数不超过K次，

且每次交易只买卖一股，返回能挣到的最大钱数

标签：[[12_动态规划]]，[[09_贪心算法]]

### 问题解析

这个的话是上面两个的拓展，首先思考，现在大于arr的一半时，此时就是与题目二情况相同，直接进行返回。

如果说k< arr.length / 2时，则：

1. 创建数组`dp[i][j]`，表示的是在0-i位置上进行交易j次此时的情况下最大钱数；
2. 接下来涉及到一个小贪心：
   1. 最后的交易不在i位置，那么`dp[i][j] = dp[i-1][j]`
   2. 最后的交易在i位置，且小贪心，i位置进行卖出操作，能取得最大值
      1. `dp[i][j] = dp[i][j-1] + prices[i] - prices[i]` ,0~i上随便交易，不超过j-1此的情况下，最后一次在i位置买，i位置卖
      2. `dp[i][j] = dp[i-1][j-1] + prices[i] - prices[i-1]`
      3. `dp[i][j] = dp[i-2][j-1] + prices[i] - prices[i-2]`
      4. ...
      5. 可以推出 `max{ dp[i][j] = dp[i][j-1] - prices[i],dp[i][j] = dp[i-1][j-1] - prices[i-1],dp[i][j] = dp[i-2][j-1] - prices[i-2],....} + prices[i]`
      6. 其实`dp[i+1][j] = max{dp[i][j],max{dp[i+1][j-1] + prices[i+1] - prices[i+1],dp[i][j-1]-prices[i],...}+prices[i+1]}`

由此，推断出每个位置的最大值，从中选择出最可能的最大值

```java
public static int maxProfit2(int[] prices, int k) {
        if (prices == null || prices.length == 0) {
            return 0;
        }
        int N = prices.length;
        if (k >= N / 2) {
            return allTrans(prices);
        }
        int[][] dp = new int[N][k + 1];
        //第一行全部都是0，第一列全部都是0
        // 求普遍位置dp[i][j]的值(含义0-i时间点随便交易，不超过j此时的情况下最大钱数)
        // 1)、最后的交易不在i位置，那么dp[i][j] = dp[i-1][j]
        // 2)、最后的交易在i位置，且小贪心，i位置进行卖出操作，能取得最大值
        //     a.dp[i][j] = dp[i][j-1] + prices[i] - prices[i] ,0~i上随便交易，不超过j-1此的情况下，最后一次在i位置买，i位置卖
        //     b.dp[i][j] = dp[i-1][j-1] + prices[i] - prices[i-1]
        //     c.dp[i][j] = dp[i-2][j-1] + prices[i] - prices[i-2]
        //     ...
        //     可以推出 max{
        //                     dp[i][j] = dp[i][j-1] - prices[i],
        //                     dp[i][j] = dp[i-1][j-1] - prices[i-1],
        //                     dp[i][j] = dp[i-2][j-1] - prices[i-2],
        //                      ....
        //                } + prices[i]

        // 其实dp[i+1][j] = max{dp[i][j],max{dp[i+1][j-1] + prices[i+1] - prices[i+1],dp[i][j-1]-prices[i],...}+prices[i+1]}
        int ans = 0;
        for (int j = 1; j <= k; j++) {
            int t = dp[0][j - 1] - prices[0];
            for (int i = 1; i < N; i++) {
                // max{dp[1][j] = dp[0][j] ,max{ dp[1][j-1]  - prices[1],dp[0][j-1] - prices[0]}+prices[1]}
                t = Math.max(t, dp[i][j - 1] - prices[i]);
                dp[i][j] = Math.max(dp[i  -1][j], t + prices[i]);
                ans = Math.max(ans, dp[i][j]);
            }
        }
        return ans;
    }

    public static int allTrans(int[] prices) {
       int ans = 0;
        for (int i = 1; i < prices.length; i++) {
            ans += Math.max(prices[i] - prices[i - 1], 0);
        }
        return ans;
    }
```

时间复杂度为$O(N \times K)$，空间复杂度为$O(N \times K)$
