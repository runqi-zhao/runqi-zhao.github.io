## 题目描述

给定一个二维数组matrix，再给定一个k值

返回累加和小于等于k，但是离k最近的子矩阵累加和

标签：[[05_前缀树]]

## 题目解析

### 想法一

定义dp[…i]为以arr[i]位置结尾的累加和，找出`dp[i]`中小于等于k的值中的最大值

<font size=5 color="red">不可以。</font>

举个例子，2，2，-1，k=0。

按照没有k的方法求出dp, dp[0] = 2, dp[1] = 4, dp[2] = 3，再从其中筛选出小于等于0的，那么没有满足的[子序列](https://so.csdn.net/so/search?q=%E5%AD%90%E5%BA%8F%E5%88%97&spm=1001.2101.3001.7020)。事实上，子序列(2,2)。即-1是满足的，应该返回-1。所以不能直接在没有k的问题的基础上修改。

### 想法二

定义dp[i]就是以array[i]结尾的小于等于k的最大值

举个例子，2, 2, -1, k = 3

如果dp[i]是以array[i]结尾的小于等于k的最大值。

那么dp[0] = 2，dp[1] = 2, dp[2]=1，但是结果是3。当计算dp[2]时，想到利用前面的，因为是-1，所以此时就算把第一个元素加入，也满足，所以不能使用dp[i-1]来得到dp[i]。

总之直接使用一维数组的kadane算法不可行。

### 想法三

一个直观的方法是计算所有的子序列和

直接将每个位置的值进行相加比较，时间复杂度$O(N^2)$。

### 想法四

用前缀和来优化。

- $ sum[i ... j] = sum[0.....j] - sum[0......i - 1]$
- 从而：
  - 要令$s u m [ i . . . j ] < = k$ 
  - 即$s u m [ 0..... j ] − s u m [ 0...... i − 1 ] < = k$ 
  - 所以有$s u m [ 0...... i − 1 ] > = s u m [ 0..... j ] − k$
- 因此：
  - 我们用一个遍历，求出每一个以$a r r [ j ]$为结尾的前缀和$su m [ 0.... j ]$
  - 然后对这个前缀和求一个下界$s u m [ 0..... j ] − k$，然后在之前的结果中查询>=这个边界的最小值，如果存在，就是一个候选值
  - 然后再把$sum(0,i)$也放入set。

```java
public static int maxSumSubmatrix(int[][] matrix, int k) {
        if (matrix == null || matrix.length == 0) {
            return 0;
        }
        int row = matrix.length;
        int col = matrix[0].length;
        int res = Integer.MIN_VALUE;
        TreeSet<Integer> sumSet = new TreeSet<>();
        for (int i = 0; i < row; i++) {
            int[] colSum = new int[col];
            for (int j = i; j < col; j++) {
                sumSet.add(0);
                int rowSum = 0;
                for (int l = 0; l < col; l++) {
                    colSum[l] += matrix[i][j];
                    rowSum += colSum[l];
                    Integer it = sumSet.ceiling(rowSum - k);
                    if (it != null) {
                        res = Math.max(res, rowSum - i);
                    }
                    sumSet.add(rowSum);
                }
                sumSet.clear();
            }
        }
        return res;
    }
```

如果不使用一定的数据结构，以上算法还是$O(n^2)$的。但是如果set的查找使用了特殊数据结构比如平衡[[搜索二叉树]]这种的，那么查找后继或者前驱就是$logn$级别了。这就是优化的一个方法。
