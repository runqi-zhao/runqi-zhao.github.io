这是 LeetCode上的 **[剑指 Offer 62. 圆圈中最后剩下的数字](https://leetcode.cn/problems/yuan-quan-zhong-zui-hou-sheng-xia-de-shu-zi-lcof/description/)** ，难度为 **简单**。

对应左神训练营第4期第4节第四题。

## 题目描述

0,1,···,n-1这n个数字排成一个圆圈，从数字0开始，每次从这个圆圈里删除第m个数字（删除后从下一个数字开始计数）。求出这个圆圈里剩下的最后一个数字。

例如，0、1、2、3、4这5个数字组成一个圆圈，从数字0开始每次删除第3个数字，则删除的前4个数字依次是2、0、4、1，因此最后剩下的数字是3。

## 题目解析

先说明”提到函数“，什么是提到函数，提到函数就是指y=x%i的形式，也就是当我经过i之后，我要返回最初的编号，函数图像如下：

![img](https://img-1312072469.cos.ap-nanjing.myqcloud.com/20181127082204156.png)

接下来我们进行一个假设：假设现在让第i号人去死，那么开始时编号是1，我所需要的号也是1，如果这时候我们需要2，所需要的号是2，一直到i+1，此时所需要的号是1，重新开始下一轮，那么我们的表达式就可以根据剃刀函数进行修改：y=(x - 1) % i + 1。也就是我们的编号与座位数进行对应的函数。

![img](https://img-1312072469.cos.ap-nanjing.myqcloud.com/20190120101020757.png)

知道编号与数字的对应关系，我们可以在进行思考新编号与旧编号之间的关系，此时我们思考一个问题：举个例子：

旧：1 2 3 ... S -1 S S + 1... i

新：i-S+1... i - 1 1 i -S

此时我们可以假设杀死i号那么在例子中，可以算出新编号的值，此时我们做出函数图像：

![img](https://img-1312072469.cos.ap-nanjing.myqcloud.com/20181127084816387.png)

那么，我们明显可以得到函数：

旧编号=（新编号+ S - 1） % i + 1；

又因为在上面的推导中，我们知道了编号=（数-1） %i + 1，假设数=m（即为死去的人是m），那么此时我们就进行修改，能得到：

旧编号 = （新编号+（m - 1） % i - 1） %i + 1

进行推导可得：

旧编号 = (新编号+m - 1) % i + 1

理由：

现在设m - 1 = ki +r, r代表余数。

此时我们进行带入，可得

旧编号 = （新编号+ r - 1） % i + 1

而我们推导的：

旧编号 = (新编号+m - 1) % i + 1 = (新编号+ ki +r - 1) % i + 1 = 新编号+ r - 1） % i + 1

因此等价，所以，最后所得公式为：

**旧编号 = (新编号+m - 1) % i + 1**

**如果发现是“剃刀”函数或者是类似剃刀函数的形式，从剃刀函数（x % i）进行找规律，然后可以代入，找到其中的规律。**

进行递归，就能得到最终结果。

```java
public static int getLive(int i, int m) {
        if (i == 1) {
            return 1;
        }
        return (getLive(i - 1, m) + m - 1) % i + 1;
    }
```

继续将递归改成循环，就有：

