## 题目描述

对于一个字符串, 从前开始读和从后开始读是一样的, 我们就称这个字符串是回文串。例如"ABCBA","AA", "A" 是回文串, 而"ABCD", "AAB"不是回文串。牛牛特别喜欢回文串, 他手中有一个字符串s, 牛牛在思考能否从字 符串中移除部分(0个或多个)字符使其变为回文串，并且牛牛认为空串不是回文串。牛牛发现移除的方案可能有 很多种, 希望你来帮他计算一下一共有多少种移除方案可以使s变为回文串。对于两种移除方案, 如果移除的字 符依次构成的序列不一样就是不同的方案。

例如，XXY 4种 ABA 5种

## 题目解析

### 说明

这是今年的原题，提供的说明和例子都很让人费解。现在根据当时题目的所有测试用例，重新解释当时的题目 含义: 

1. "1AB23CD21"，你可以选择删除A、B、C、D，然后剩下子序列{1,2,3,2,1}，只要剩下的子序列是同一个，那 么就只算1种方法，和A、B、C、D选择什么样的删除顺序没有关系
2. "121A1"，其中有两个{1,2,1}的子序列，第一个{1,2,1}是由{位置0，位置1，位置2}构成，第二个{1,2,1} 是由{位置0，位置1，位置4}构成。这两个子序列被认为是不同的子序列。也就是在本题中，认为字面值一样 但是位置不同的字符就是不同的。 
3. 其实这道题是想求，str中有多少个不同的子序列，每一种子序列只对应一种删除方法，那就是把多余的东 西去掉，而和去掉的顺序无关。
4. 也许你觉得我的解释很荒谬，但真的是这样，不然解释不了为什么，XXY 4种 ABA 5种，而且其他的测 试用例都印证了这一点。

### 思路

范围模型。

怎么说呢这个...边界条件太多了。

先回想[[牛客_蛇蛇数组]]，这个也是使用边界模型进行实现，分为四种情况

1. i位置不要，j位置不要：此时认为存在回文串的个数为a
2. i位置不要，j位置要：此时认为存在回文串的个数为b
3. i位置要，j位置不要：此时认为存在回文串的个数为c
4. i位置要，j位置要：此时认为存在回文串的个数为d

认为`dp[i][j]`代表的在空串不算回文串的情况下，求str[i..j]有多少不同的回文子序列。那么思考：`dp[i][j]`存在的序列情况就是a+b+c,同时思考`dp[i +1][j]`代表的i位置不要，j位置要存在的字符串，为a+b，同理`dp[i][j-1]`是a+c，因此，到最后我们需要减去一个a，才能写出动态方程，即：
$$
dp[i][j]=dp[i+1][j]+dp[i][j−1]−dp[i+1][j−1];
$$


对于情况4，只有在`str[i]==str[j]`时，才考虑，此时为a+1（此时中间为空串是可以的）

因此，可做出

```java
public static int way2(String s) {
        if (s == null || s.length() == 0) {
            return 0;
        }
        int N = s.length();
        char[] str = s.toCharArray();
        int[][] dp = new int[N][N];
        for (int i = 0; i < N; i++) {
            dp[i][i] = 1;
        }
        for (int i = 0; i < N - 1; i++) {
            dp[i][i + 1] = str[i] == str[i + 1] ? 3 : 2;
        }

        for (int i = N - 3; i >= 0; i--) {
            for (int j = i + 2; j < N; j++) {
                dp[i][j] = dp[i + 1][j] + dp[i][j - 1] - dp[i + 1][j - 1];
                if (str[i] == str[j]) {
                    dp[i][j] += dp[i + 1][j - 1] + 1;
                }
            }
        }
        return dp[0][N - 1];
    }
```
