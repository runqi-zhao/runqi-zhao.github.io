## 题目描述

给定一棵二叉树的头节点head，已知所有节点的值都不一样，返回其中最大的且符合搜索二叉树条件的拓扑结构的大小。

拓扑结构：不是子树，只要能连起来的结构都算。

## 题目解析

### 方法一

我们对于每个结点进行位置查找，查找每个位置对应的符合的拓扑结构，到下一个结点时，重新进行查找，找到每个位置的拓扑高度（可以使用先序遍历，将每个位置左右子树进行遍历，如果符合条件，则继续遍历，如果不符合条件，将这个结点的所有子树进行舍弃）以此得出每个子结点的值，从而得到对应的结果。

```java
public static class Node {
        public int value;
        public Node left;
        public Node right;

        public Node(int value) {
            this.value = value;
        }
    }

    public static int bstTopoSize1(Node head) {
        if (head == null) {
            return 0;
        }
        int max = maxTopo(head, head);
        max = Math.max(bstTopoSize1(head.left), max);
        max = Math.max(bstTopoSize1(head.right), max);
        return max;
    }

    public static int maxTopo(Node h, Node n) {
        if (h != null && n != null && isBSTNode(h, n, n.value)) {
            return maxTopo(h, n.left) + maxTopo(h, n.right) + 1;
        }
        return 0;
    }

    public static boolean isBSTNode(Node h, Node n, int value) {
        if (h == null) {
            return true;
        }
        if (h == n) {
            return true;
        }
        return isBSTNode(h.value > value ? h.left : h.right, n, value);
    }
```

此方法在最差情况下时间复杂度可以达到$O(N^3)$。

### 方法二

使用二叉树的递归套路，首先当我们知道每个结点左右子树分别贡献多少，我们称之为拓扑贡献记录，举例说明

![image-20220928163218107](https://img-1312072469.cos.ap-nanjing.myqcloud.com/image-20220928163218107-e2ec72994e09d7546edeba17a7cd3aac.png)

上述节点中，先看最左结点的2，此时他的左右结点贡献的是0（不存在），最后一排子结点都是如此，再看4，对于4而言，其左右子树都符合拓扑结构，因此将左右子树贡献的进行记录，每个节点都是如此。

接着我们如果10上面存在一个结点9，10为其右子树，此时我们更新拓扑结构，看10的左子树是否都符合，判断为不符合，进行舍弃，同时更新其中拓扑贡献记录。右子树14全部符合，此时保留，在进行舍弃之后，我们就能得到对应的每个结点的拓扑贡献记录。

```java
public static class Record {
        public int left;
        public int right;

        public Record(int left, int right) {
            this.left = left;
            this.right = right;
        }
    }

    public static int bstTopoSize2(Node head) {
        Map<Node, Record> map = new HashMap<>();
        return posOrder(head, map);
    }

    public static int posOrder(Node head, Map<Node, Record> map) {
        if (head == null) {
            return 0;
        }
        int ls = posOrder(head.left, map);
        int rs = posOrder(head.right, map);
        Record lr = map.get(head.left);
        Record rr = map.get(head.right);
        int lbst = lr == null ? 0 : lr.left + lr.right + 1;
        int rbst = rr == null ? 0 : rr.left + rr.right + 1;
        map.put(head, new Record(lbst, rbst));
        return Math.max(lbst + rbst + 1, Math.max(ls, rs));
    }
```

此过程时间复杂度是$O(N)$，在时间复杂度估算方面，与Morris遍历相似，可以回想一下。
