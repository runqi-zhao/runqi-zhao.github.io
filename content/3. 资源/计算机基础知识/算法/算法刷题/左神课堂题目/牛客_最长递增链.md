# 最长递增链

这是 牛客上的 **[最长递增链](https://www.nowcoder.com/questionTerminal/56cf3f20f45743439e99452dce599123)** ，难度为 **三颗星**。
对应左神训练营第4期第1节第1题。

标签：[[12_动态规划]],[[11_暴力递归]]

## 题目描述

给定一个二维数组matrix，可以从任何位置出发，每一步可以走向上、下、左、右，四个方向。返回最大递增链的长度。

**输入描述:**

```ini
第一行输入N和M，表示矩阵行列数，N，M<=2000
接下来N行每行M个整数，表示这个矩阵
```

**输出描述:**

```ini
输出一个数，表示最大递增链的长度
```

示例1

输入

```ini
3 3
5  4  3
3  1  2
2  1  3
```

输出

```ini
5
```

说明

```ini
1-2-3-4-5
```

示例2

输入

```ini
3 3
1 2 3 
6 5 4 
7 8 9
```

输出

```ini
9
```

说明

```ini
1-2-3-4-5-6-7-8-9
```

## 题目解析

此题目首先先使用[[11_暴力递归]]的方法，每个位置都进行遍历，从中选择出最长的递增链，代码如下：

```java
 public static int maxPath(int[][] matrix) {
        int ans = Integer.MIN_VALUE;
        for (int row = 0; row < matrix.length; row++) {
            for (int col = 0; col < matrix[0].length; col++) {
                ans = Math.max(ans, process(matrix, row, col));
            }
        }
        return ans;
    }

    // 假设在matrix中，从i行，j列出发，能走出的最长递增路径，返回最长递增路径的长度
    public static int process(int[][] matrix, int i, int j) {
        if (i < 0 || i >= matrix.length || j < 0 || j >= matrix[0].length) {
            return -1;
        }
        int up = 0;
        int down = 0;
        int left = 0;
        int right = 0;
        if (i - 1 >= 0 && matrix[i - 1][j] > matrix[i][j]) {
            up = process(matrix, i - 1, j);
        }
        if (i + 1 < matrix.length && matrix[i + 1][j] > matrix[i][j]) {
            down = process(matrix, i + 1, j);
        }
        if (j - 1 >= 0 && matrix[i][j - 1] > matrix[i][j]) {
            left = process(matrix, i , j - 1);
        }
        if (j + 1 < matrix[0].length && matrix[i][j + 1] > matrix[i][j]) {
            right = process(matrix, i, j + 1);
        }
        return 1 + Math.max(Math.max(up, down), Math.max(left, right));
    }
```

### 改进一

每个位置都进行遍历，那么可能上次进行遍历之后，下次重新进行遍历，那么，可以设计一个“缓存”，记录下来每个位置的值，当其中的值不为0的时候，直接到下一层遍历。

```java
public static int maxPath2(int[][] matrix) {
        int ans = Integer.MIN_VALUE;

        int[][] dp = new int[matrix.length][matrix[0].length];

        for (int row = 0; row < matrix.length; row++) {
            for (int col = 0; col < matrix[0].length; col++) {
                ans = Math.max(ans, process(matrix, row, col, dp));
            }
        }
        return ans;
    }

    // 假设在matrix中，从i行，j列出发，能走出的最长递增路径，返回
    // dp[i][j] == 0 process(i,j) 之前没遇到过
    // dp[i][j] != 0 process(i,j) 之前已经算过了
    public static int process(int[][] matrix, int i, int j, int[][] dp) {
        if (i < 0 || i >= matrix.length || j < 0 || j >= matrix[0].length) {
            return -1;
        }
        if (dp[i][j] != 0) {
            return dp[i][j];
        }
        int up = 0;
        int down = 0;
        int left = 0;
        int right = 0;
        if (i - 1 >= 0 && matrix[i - 1][j] > matrix[i][j]) {
            up = process(matrix, i - 1, j, dp);
        }
        if (i + 1 < matrix.length && matrix[i + 1][j] > matrix[i][j]) {
            down = process(matrix, i + 1, j, dp);
        }
        if (j - 1 >= 0 && matrix[i][j - 1] > matrix[i][j]) {
            left = process(matrix, i , j - 1, dp);
        }
        if (j + 1 < matrix[0].length && matrix[i][j + 1] > matrix[i][j]) {
            right = process(matrix, i, j + 1, dp);
        }
        int ans = 1 + Math.max(Math.max(up, down), Math.max(left, right));
        dp[i][j] = ans;
        return ans;
    }
```

### 改进二

继续思考，如果此时有一个值，记录从上一步来的位置，那么，不妨设：

1. `dp[i][j]`代表的是位置，即在i,j位置的最长链；
2. 用p记录上面的一次值，代表的是上一步值是什么；
3. 则需要的从(i,j)位置出发，走出的最长链，要求：上一步是可以迈到当前步上的

则得出，记录上一步来的值，每次走的时候确认出当前最大的值，接着再将这个位置的最大值传入下一步，从而得到每个位置的最长链，精工比较最终得出最长链。

```java
public static int longestIncreasingPath(int[][] m) {
        if (m == null || m.length == 0 || m[0].length == 0) {
            return 0;
        }
        int[][] dp = new int[m.length][m[0].length];
        // dp[i][j] (i,j)出发，走出的最长链长度
        int max = 0;
        for (int i = 0; i < m.length; i++) {
            for (int j = 0; j < m[0].length; j++) {
                // 每一个(i,j)位置出发，都尝试
                max = Math.max(max, maxIncrease(m, dp, i + 1, j, m[i][j]) + 1);
                max = Math.max(max, maxIncrease(m, dp, i, j + 1, m[i][j]) + 1);
                max = Math.max(max, maxIncrease(m, dp, i - 1, j, m[i][j]) + 1);
                max = Math.max(max, maxIncrease(m, dp, i, j - 1, m[i][j]) + 1);
            }

       }
       return max;
   }

    // 来到的当前位置是i,j位置
    // p 上一步值是什么
    // 从(i,j)位置出发，走出的最长链，要求：上一步是可以迈到当前步上的
    public static int maxIncrease(int[][] m, int[][] dp, int i, int j, int p) {
       if (i < 0 || i >= m.length || j < 0 || j >= m[0].length || m[i][j] <= p) {
           return 0;
       }
       if (dp[i][j] == 0) { //i,j出发，当前没算过
           dp[i][j] = maxIncrease(m, dp, i + 1, j, m[i][j]) + 1;
           dp[i][j] = Math.max(dp[i][j], maxIncrease(m, dp, i, j + 1, m[i][j]) + 1);
           dp[i][j] = Math.max(dp[i][j], maxIncrease(m, dp, i - 1, j, m[i][j]) + 1);
           dp[i][j] = Math.max(dp[i][j], maxIncrease(m, dp, i, j - 1, m[i][j]) + 1);
       }
       return dp[i][j];
    }
```

此时的时间复杂度为$O(M \times N)$，空间复杂度为$O(M \times N)$。
