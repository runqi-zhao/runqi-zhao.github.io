## 题目描述

给定一个正数1，裂开的方法有一种，(1) 给定一个正数2，裂开的方法有两种，(1和1)、(2) 给定一个正数3，裂开的方法有三种，(1、1、1)、(1、2)、(3) 给定一个正数4，裂开的方法有五种，(1、1、1、1)、(1、1、2)、(1、3)、(2、2)、 (4)

给定一个正数n，求裂开的方法数。 动态规划优化状态依赖的技巧

## 题目解析

### **方案一：暴力递归**

f ( pre, rest )

- pre 只之前裂开的数
- rest 是本次要裂开的数。rest 要大于 pre。
- 返回结果：裂开的方法数

最终结果：f(1, n)

可能性分析：

从左向右的尝试模型。

f(i,j) 依赖：f(i+1, rest - (i+1))+ ...+ f(n, n)

```java
public static int ways1(int n) {
        if (n == 0) {
            return 0;
        }
        return process(1, n);
    }

    /**
     * @param pre  要裂开rest的，前一个约束(rest裂开的第一个部分不能<pre)
     * @param rest 还剩多少值，需要去裂开
     * @return 裂开的方案数
     */
    public static int process(int pre, int rest) {
        //之前裂开的方案，构成了1种有效方法
        if (rest == 0) {
            return 1;
        }
        //如果是非递增
        if (pre > rest) {
            return 0;
        }
        int ways = 0;
        for (int i = pre; i <= rest; i++) {
            ways += process(i, rest - i);
        }
        return ways;
    }
```

### **方案二：动态规划**

![screenshot-20221025-130043.png](https://img-1312072469.cos.ap-nanjing.myqcloud.com/da95697788984fb08f5fa3a2a2c06eef~tplv-k3u1fbpfcp-zoom-in-crop-mark:4536:0:0:0.awebp)

之后的话我们先根据递归改出一个“粗糙”版本的动态规划，首先我们将pre做行，rest做列，其中的含义不变，范围都规定在0->n+1，可以知道，第一行是没有意义的，同时我们可以知道，第一列都是1（rest==0），同时，我们可得出右半区域都是0（pre>rest）,因此我们将已经知道的位置进行填充，然后将剩下位置进行补充。

首先我们得知道都依赖于左半边以及下面的区域，因此，我们开始时从最后一行开始（此时左半边以及下边都已知），然后从左向右进行遍历，得出每个位置的结果，最后得出的答案是在pre=1，rest=n时的答案，可以写出代码：

```java
  public static int ways2(int n) {
        if (n == 0) {
            return 0;
        }
        int[][] dp = new int[n + 1][n + 1];
        for (int pre = 1; pre <= n; pre++) {
            dp[pre][0] = 1;
        }
        for (int pre = n; pre >= 1; pre--) {
            for (int rest = pre; rest <= n; rest++) {
                int ways = 0;
                for (int i = pre; i <= rest; i++) {
                    ways += dp[i][rest - i];
                }
                dp[pre][rest] = ways;
            }
        }
        return dp[1][n];
    }
```

### **方案三：动态规划--斜率优化**

**斜率优化：看看邻近的解能否替换枚举行为。**

![screenshot-20221025-130057.png](https://img-1312072469.cos.ap-nanjing.myqcloud.com/df39128486294096aa0ccba8d34e6a50~tplv-k3u1fbpfcp-zoom-in-crop-mark:4536:0:0:0.awebp)

```java
public static int ways3(int n) {
        if (n == 0) {
            return 0;
        }
        int[][] dp = new int[n + 1][n + 1];
        for (int pre = 1; pre <= n; pre++) {
            dp[pre][0] = 1;
        }
        for (int pre = 1; pre <= n; pre++) {
            dp[pre][pre] = 1;
        }
        for (int pre = n; pre >= 1; pre--) {
            for (int rest = pre + 1; rest <= n; rest++) {
                dp[pre][rest] = dp[pre + 1][rest] + dp[pre][rest - pre];
            }
        }
        return dp[1][n];
    }
```

## 总结

斜率优化确实不常见，可以通过举例子来解决。
