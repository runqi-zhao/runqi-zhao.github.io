题目一

给定一个正数1，裂开的方法有一种，(1) 给定一个正数2，裂开的方法有两种，(1和1)、(2) 给定一个正数3，裂开的方法有三种，(1、1、1)、(1、2)、(3) 给定一个正数4，裂开的方法有五种，(1、1、1、1)、(1、1、2)、(1、3)、(2、2)、 (4)

给定一个正数n，求裂开的方法数。 动态规划优化状态依赖的技巧

解析

先说明暴力递归。

常见的思路可以理解为：首先将一个数视为(1,n)，拿4进行举例，首先进行f(1,n)的调用，代表第一个数不能小于1，然后剩下的数为n-1，接下来进行f(2,2)的调用，如果前面的数大于后面的数，无效，当后面的数到达0时，这是一种有效方案，进行返回。

之后的话我们先根据递归改出一个“粗糙”版本的动态规划，首先我们将pre做行，rest做列，其中的含义不变，范围都规定在0->n+1，可以知道，第一行是没有意义的，同时我们可以知道，第一列都是1（rest==0），同时，我们可得出右半区域都是0（pre>rest）,因此我们将已经知道的位置进行填充，然后将剩下位置进行补充。

首先我们得知道都依赖于左半边以及下面的区域，因此，我们开始时从最后一行开始（此时左半边以及下边都已知），然后从左向右进行遍历，得出每个位置的结果，最后得出的答案是在pre=1，rest=n时的答案，可以写出代码：

题目二

给定一个整数N，代表你有1～N这些数字。在给定一个整数K。你可以随意排列这些数字，但是每一种排列都有若干个逆序对。返回有多少种排列，正好有K个逆序对

例子1:

Input: n = 3, k = 0

Output: 1

解释：

只有[1,2,3]这一个排列有0个逆序对。

例子2:

Input: n = 3, k = 1

Output: 2

解释

[3,2,1]有(3,2)、(3,1)、(2,1)三个逆序对，所以不达标。

达标的只有：

[1,3,2]只有(3,2)这一个逆序对，所以达标。

[2,1,3]只有(2,1)这一个逆序对，所以达标。

解析

在这道题目中，我们首先得知道什么叫做逆序对，例子已经说明，看到了两个参数的要求，我们其实可以想到动态规划，两个参数，完全可以想到一个样本做行，一个样本做列的情况。

因此我们将n作为行，k作为列，行的范围时0-n，类的范围是0-k

第一行是没有意义的，可以忽略。（n=0）第二行中，只存在一个数，此时只有（k=0,n=1）的位置时1，其余位置都是0；再看第一列，当我们要求0个逆序对(k=0),此时都是1，因此我们能够得出基本位置。

此时去递推普通位置，依旧是从例子入手。

假设我们现在需要（7，3）的位置，那么我们就先假设我们已知(6,3)的值，最后的7如果插入在最后的位置，不增加逆序对，此时的值就是(6,3)；插入在倒数第二位置，此时产生一个逆序对，也就是(6,2)；以此类推，能到(6,0)；

再假设我们下载需要（7,8）的位置，那么也假设我们已知对应位置的值，插入在最后，为（6，8），以此类推，但是到最后我们到的位置是（6，2），因为如果再往前面，产生的逆序对将不满足。

抽象出来，可以得到如下公式：

dp[n][k]={dp[n−1][k..0]n>kdp[n−1][k..k−n+1]k>=n​​

因此，可以写出第一版“粗糙”的动态规划。

其中有枚举行为，我们可以使用斜率优化，依旧使用例子。

对于（7，3），我们如果知道了 是dp[6][3..0]，但是对于(7，2)，以来的是dp[6][2..0]，因此这个位置就可以使依赖于(7,2)与(6,3)。

对于（7，8），上面知道了是依赖于dp[6][8..2]，此时的（7，7），依赖的是dp[6][7..1]，此时我们需要加上一个(6,8)同时减去一个(6,1)。

对于极端位置（k=1），此时也是满足。

抽象出来，得公式：

dp[n][k]={dp[n][k−1]+dp[n−1][k]n>kdp[n−1][k]+dp[n][k−1]−dp[n−1][k−n]k>=n​​

题目三

给定一棵二叉树的头节点head，已知所有节点的值都不一样，返回其中最大的且符 合搜索二叉树条件的最大拓扑结构的大小。

拓扑结构：不是子树，只要能连起来的结构都算。

解析

方法一

我们对于每个结点进行位置查找，查找每个位置对应的符合的拓扑结构，到下一个结点时，重新进行查找，找到每个位置的拓扑高度（可以使用先序遍历，将每个位置左右子树进行遍历，如果符合条件，则继续遍历，如果不符合条件，将这个结点的所有子树进行舍弃）以此得出每个子结点的值，从而得到对应的结果。

此方法在最差情况下时间复杂度可以达到O(N3​)。

方法二

使用二叉树的递归套路，首先当我们知道每个结点左右子树分别贡献多少，我们称之为拓扑贡献记录，举例说明

上述节点中，先看最左结点的2，此时他的左右结点贡献的是0（不存在），最有一排子结点都是如此，再看4，对于4而言，其左右子树都符合拓扑结构，因此将左右子树贡献的进行记录，每个节点都是如此。

接着我们如果10上面存在一个结点9，10为其右子树，此时我们更新拓扑结构，看10的左子树是否够符合，判断为不符合，进行舍弃，同时更新其中拓扑贡献记录。右子树14全部符合，此时保留，在进行舍弃之后，我们就能得到对应的每个结点的拓扑贡献记录。

此过程时间复杂度是O(N)，在时间复杂度估算方面，与Mirrors遍历相似，可以回想一下。

题目四

给定一个长度为偶数的数组arr，长度记为2*N。前N个为左部分，后N个为右部分。 arr就可以表示为{L1,L2,..,Ln,R1,R2,..,Rn}， 请将数组调整成{R1,L1,R2,L2,..,Rn,Ln}的样子。

解析

这道题目用到了数论的结论。

首先我们先假设一个简单情况：L1，L2，L3，L4，R1，R2，R3，R4。这8个数要进行交换，使其中的数满足上面的条件，我们将L1应放在L2的位置（位置*2），同时R1放在L1的位置(2 * (位置 - n) - 1)。

但是存在一个问题，当我们长度为6时，一个环并不能将所有的位置进行调整，但是这时已经将对应位置进行了调整，因此需要使用数论中的一个结论。

N（偶数）

当N = 3k−1

存在的结论：不同环的触发点：1，3，9…3

因此，我们将一个环进行分解，将每个环对应的位置先进行反转，然后将其中的位置进行调整，以此类推。

注意，要将对应的位置先进行调整，保证对应的位置能够满足模型应有的位置。

这个模型很重要

题目五

一个不含有负数的数组可以代表一圈环形山，每个位置的值代表山的高度。比如， {3,1,2,4,5}、{4,5,3,1,2}或{1,2,4,5,3}都代表同样结构的环形山。 山峰A和山峰B能够相互看见的条件为: 1.如果A和B是同一座山，认为不能相互看见。 2.如果A和B是不同的山，并且在环中相邻，认为可以相互看见。 3.如果A和B是不同的山，并且在环中不相邻，假设两座山高度的最小值为min。

  1. 如果A通过顺时针方向到B的途中没有高度比min大的山峰，认为A和B可以相互 看见
  2. 如果A通过逆时针方向到B的途中没有高度比min大的山峰，认为A和B可以相互 看见
  3. 两个方向只要有一个能看见，就算A和B可以相互看见 给定一个不含有负数且没有重复值的数组 arr，请返回有多少对山峰能够相互看见。

进阶: 给定一个不含有负数但可能含有重复值的数组arr，返回有多少对山峰能够相互看见。

解析

单调栈使用：关心旁边离得最近的最小值，然后还要求O(N)

这道题目的意思是对于一个环，每个相邻的都是可以看见的，{3,1,2,4,5}中，{3，2}可达，{3，4}，{3，5}可达，其余的都不可达。

先说不存在重复的环，此时我们找到最大值，再找到次大值，此时是可达的，以此类推，可以把不相邻的情况都找到

当环形结构中只有一座山峰时，可见山峰对数量为0。当有两座时，可见山峰对数量为1。当有三座时可见山峰对数量为3。可以推导得出当有n座山峰时，可见山峰对数量为2 * n - 3；

假设环形结构中有n座山峰，除了最高山峰和次高山峰外还剩下n - 2座山峰，这n - 2座山峰中每一座都能根据小找大的方式找到两对，所以一共有(i - 2) * 2对，再加上最高山峰和次高山峰这对，一共就有2 * n - 3对。

对于相邻，我们需要使用单调栈的思想，此时我们将其中最大值的值都放入单调栈之中，同时记录出现的次数，然后进行逆时针遍历，小于等于则直接放入，如果大于，则弹出当前的值，拥有的个数是（2∗频率+CK2​），此时就能得到对应的个数，最后将栈中对应 个数进行弹出，同时也应该满足对应的情况。就能得到最终的解。
